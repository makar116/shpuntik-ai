# 🤖 Шпунтик — личный ИИ-ассистент

Платформа на базе Dify + OpenRouter + GLM-5.2.

## Домены
- https://shpuntikai.ru — основной чат
- https://api.shpuntikai.ru — API (Telegram webhook)
- https://admin.shpuntikai.ru — админка Dify

## Структура
- `nginx/` — конфиги nginx (хостовой reverse proxy)
- `dify/` — конфигурация Dify
- `ai-fabrica/` — legacy проект

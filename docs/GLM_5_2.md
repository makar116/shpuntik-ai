## 4. Архитектура Шпунтика (текущая)
### 4.1. Dify-приложение «Шпунтик-чат» (тип CHATFLOW!)
- URL редактора: admin.shpuntikai.ru/app/ddca1171-89b0-427b-a98c-233180f8544b/workflow
- Схема:
  НАЧАЛО → [Поиск знаний (query=sys.query, база=Профиль Андрея)]
           → [LLM «Шпунтик: основная», модель Qwen3 Max, retry 3×1s,
              обработка ошибок = fail-branch, контекст = {{#context#}}]
              —успех→ [ОТВЕТ: LLM.text]
              └—ошибка→ [LLM 2, модель glm-5.2] → [ОТВЕТ 2: LLM2.text]
- У обоих LLM Max Tokens = 8192 (иначе 402 при малом балансе OpenRouter).
- Память диалога — встроенная chatflow.
- Системный промпт (основной):
  «Ты — Шпунтик, личный ИИ-ассистент Андрея. Характер: дружелюбный, с лёгкой
  иронией, без пафоса. Ты как технически подкованный друг: говоришь просто и по
  делу, без воды. Правила: 1. Отвечай на русском, если не попросили иначе.
  Про код — давай готовый рабочий код с краткими комментариями. 3. Не уверен —
  честно скажи и предложи уточнить. 4. Если задача выглядит очень сложной — скажи:
  „Кажется, тут нужна тяжёлая артиллерия". 5. Помни контекст разговора и
  предыдущие договорённости. 6. Короткие ответы по умолчанию; длинные — только
  когда задача требует.»
- Промпт эскалации (glm-5.2): тот же + «Предыдущая попытка ответить завершилась
  ошибкой, и ты включился как тяжёлая артиллерия. Реши задачу максимально тщательно,

## 8. Уроки/грабли (учитывать при дальнейшей работе)
- Dify: workflow ≠ chatflow. Узел «Ответ» есть ТОЛЬКО в chatflow; в workflow — «Вывод»(End).
- API-ключи Dify — per-app: ключ не от того приложения даёт ошибку not_chat_app.
- OpenRouter 402 = баланс < запрошенных max_tokens.
- Telegram 409 = одновременно два polling-инстанса бота.
- MobaXterm: длинные heredoc иногда «рвутся» — использовать уникальный маркер
  (ENDOFFILE) и проверять файл (wc -l, head, tail).
- GitHub: только PAT/SSH; push protection блокирует секреты автоматически.
- systemd + EnvironmentFile — стандарт для секретов и автозапуска.
- nginx Basic Auth + файл паролей: права должны быть 640 root:www-data,
  иначе nginx worker (www-data) не прочитает → 500.
- База знаний: сегментация `\n\n` (по абзацам) лучше, чем `\n` (по строкам).
- OpenRouter-ключ хранится в двух местах (Dify + /root/secrets/tg.env для монитора
  баланса) — при ротации обновлять оба, иначе монитор баланса сломается молча.
